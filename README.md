# Nitesh Thakur Portfolio

Modern developer portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.tsx` to replace the placeholder projects, email, GitHub, LinkedIn, skills, and bio.

Put your resume at:

`public/resume.pdf`
